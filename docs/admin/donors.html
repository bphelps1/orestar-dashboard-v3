Cash on Hand vs ORESTAR

Each discrepancy compares the app balance already published from an exact, fingerprinted transaction snapshot with the ORESTAR ending balance read during its matching capture window. If either side changes afterward, the pair moves to “needs refresh” instead of remaining an active discrepancy.

Dormant committees have no transactions in the year ORESTAR reports. ORESTAR carries their balance forward anyway, so a gap there usually means missing history rather than something wrong today.
